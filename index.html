EOTC-US

Web & mobile

I built a directory to help people find Ethiopian Orthodox churches across the United States. It also includes faith resources in English and Amharic.

  • Search, state and city filters, and location-based sorting for 193 church listings.
  • Language switching for 14 bilingual articles.
  • A website deployed on Vercel and a companion React Native app.

TypeScript · JavaScript · React Native · Expo · Supabase · Vercel

Mezgebe Tselot

Mobile app

An English and Amharic reading app with verse search, bookmarks, and saved reading progress. I wanted readers to be able to find a passage and pick up where they left off.

  • Search across Bible books and chapters stored in the app.
  • Bookmarks and reading progress saved with AsyncStorage.
  • Church browsing with a fallback when location permission is unavailable.

React Native · Expo · TypeScript · AsyncStorage

DMKM Church Website

Website

A church website with English and Amharic language options. I organized the content so visitors can find sermons, Sunday School information, resources, and contact details.

  • Four sections with shared navigation and reusable components.
  • Language switching with react-i18next.
  • Responsive layouts, an image carousel, and video lists.

React · JavaScript · Tailwind CSS · react-i18next
